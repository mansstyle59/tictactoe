# Coach IA 1.0

Séances de sport guidées par la voix, adaptées au temps disponible, à la maison ou en salle :
gestes animés, machines de salle, fiches d'exercices, profils avec pseudo et mot de passe, suivi des progrès.

Application web statique : `index.html` et le dossier `audio/` (voix des consignes).
